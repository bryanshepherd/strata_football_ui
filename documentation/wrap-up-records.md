# Records in game reports

Saved Game Wrap-Up records take precedence over the original game-setup records in the scoring summary and the basic Sidearm XML. Precedence is per field: setup provides fields that were never entered in wrap-up, including a conference label. An explicitly cleared wrap-up field stays empty instead of restoring an older value.

The report displays the operator's saved values exactly; it does not add a win or loss or rewrite either set of saved records. The example game follows the same precedence as all other games.
